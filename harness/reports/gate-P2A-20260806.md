## 詳細と根拠

### G-P2A-1: バッチ実行
`cd backend && .venv\Scripts\python.exe -m batch.lift_batch` を実行し、正常終了。
`run()` の戻り値を直接確認：
```
{'generated': 16, 'high_lift_low_corate': 6}
```
`data/co_purchase.json` に16行が出力され、うち6行が `high_lift_low_corate: true`。

### G-P2A-2: 再現性
同一コマンドを連続2回実行し、`data/co_purchase.json` の md5 を比較。

```
run1: e184e2267d4373f0fcd804f5d895ce06
run2: e184e2267d4373f0fcd804f5d895ce06
diff run1 run2 → 差分なし（IDENTICAL）
```
`compute_metrics` が丸め桁数（support=4桁, confidence=3桁, lift=2桁）を固定し、`write_output` が
`json.dumps(..., indent=2)` で決定的にシリアライズしているため、同一入力から同一バイト列が得られる
ことを確認した。

### G-P2A-3 / G-P2A-4: 式の独立検算・伸びしろ判定の独立照合
実装コード（`batch.lift_batch`）を一切 import せず、QA が別途作成した独立スクリプト
（`independent_verify.py`、`co_purchase_source.json` と `co_purchase.json` のみを読み込む）で、
**全16ペア**について
- `support = round(co_support, 4)`
- `confidence = round(co_support / support_A, 3)`
- `lift = round(co_support / (support_A * support_B), 2)`
- `co_purchase_rate = round(co_support, 4)`
- `high_lift_low_corate = (lift >= 2.0) and (co_purchase_rate <= 0.045)`

を再計算し、`data/co_purchase.json` の値と1行ずつ突合。全16行が完全一致（`Mismatches: 0`）。
加えて3ペア（リビングテーブル→照明、デスク→ラグ・カーペット、食器→カーテン）については
手計算（電卓レベルの割り算）を別途記載し、丸め前の値まで一致を確認した（例:
デスク→ラグ・カーペット: 0.0378/(0.09×0.14) = 3.0 → lift=3.0、`high_lift_low_corate=true`
（lift>=2.0 かつ co_purchase_rate=0.0378<=0.045））。
証跡: `evidence/P2A/independent_verify_output.txt`

### G-P2A-5: 単体テスト緑＋実質性
`pytest tests/unit -v` で `test_lift_batch.py` の11ケースを含む全38ケースが PASS。
`test_lift_batch.py` を読んだ結果、以下がハリボテでなく実際にアサートされていることを確認：
- 手計算値（`0.3/0.5=0.6`, `0.3/(0.5*0.4)=1.5` 等）を docstring に明記した上で `pytest.approx` で厳密比較
- confidence の非対称性（A→B と B→A で異なる値になること）を明示的に検証
- 境界値: lift/co_purchase_rate がちょうど閾値のとき True、閾値をわずかに下回るとき False（丸め後1.99での判定も含む）
- 再現性: 同一入力を2回 `compute_metrics` に通し `rows_1 == rows_2` と JSON文字列一致を assert
- 未知の cat_mid 参照で `ValueError` が送出されることを確認（サイレント失敗を防ぐ設計の検証）
- 出力スキーマの列集合が既存 `co_purchase.json` と一致することを確認
- `run()` を実データ（本番 `co_purchase_source.json`）に対して tmp_path で実行し、生成された全行の
  `cat_mid_a`/`cat_mid_b` が本番 `products.json` の `cat_mid` に実在することを確認（参照整合）

いずれも定数のみをアサートする空虚なテストではなく、入力→出力の因果関係を検証する実質的なテスト
であることを確認した。
