# セキュリティ是正レポート（既存脆弱性の解消）— 2026-08-09

- 対象: `npm audit`（frontend）／`pip-audit`（backend）で検出された既存脆弱性
- 方針: いずれも開発/ツール依存（本番バンドル `dist/` 非同梱）だが全解消。修正後に全テストで無回帰確認。

| 領域 | パッケージ | 深刻度 | 内容 | 依存経路 |

## 是正内容

- **frontend**: `frontend/package.json` に `overrides` を追加し、transitive 依存を patched 版に固定。
  - `js-yaml` → **4.3.1**（v4-legacy の修正版）
  - `uuid` → **11.1.1**（修正版）
  - `npm install --legacy-peer-deps`（既存の typescript peer 条件を踏襲）で反映。
- **backend**: `backend/requirements.txt` の `pytest>=8.0,<9.0` を **`pytest>=9.0.3,<10.0`** に更新（導入は 9.1.1）。
