# Room Harmony デザインシステム（ニトリネット準拠）

将来ニトリネット（公式アプリ）の一部として組み込むことを見据え、**ニトリネットのデザイン言語**に合わせた
視覚トークンとコンポーネント様式を定義する。現行ニトリネット（nitori-net.jp）の公開UIから抽出した
配色・タイポグラフィ・角丸・コンポーネント傾向に基づく。

> 商標・著作権への配慮: 本システムは**デザイン言語（配色・型・レイアウトの質感）**の適用にとどめ、
> ニトリの**ロゴ・独自画像アセットは複製しない**。ブランドマークは実運用時にニトリ提供の正規アセットへ
> 差し替える前提のテキストワードマーク／プレースホルダとする。なりすまし表示はしない。

## 1. カラートークン（抽出値ベース）

| セマンティック変数 | 値 | 用途 | 由来（ニトリネット抽出） |
|---|---|---|---|
| `--rh-brand` | `#009E96` | ブランド主要色（アクセント・ヘッダー帯・アイコン） | 背景で最多のティールグリーン |
| `--rh-primary` | `#008078` | 主要ボタン背景（白文字で AA大 を満たすようやや暗く） | brand を暗色化 |
| `--rh-primary-hover` | `#006E67` | 主要ボタン hover/active | 派生 |
| `--rh-on-primary` | `#FFFFFF` | 主要ボタン上の文字 | — |
| `--rh-heading` | `#14293A` | 見出し・重要テキスト（濃紺） | 見出し色 |
| `--rh-text` | `#333333` | 本文 | body color |
| `--rh-text-muted` | `#6D6D6D` | 補助テキスト・分類パス | 補助テキスト |
| `--rh-link` | `#1F73B7` | リンク（ニトリの #53A4EF を AA 確保のため暗色化） | link blue 派生 |
| `--rh-price` | `#E8352A` | 価格・セール（赤・太字。#FF3A2E を僅かに暗く AA 寄せ） | price red |
| `--rh-bg` | `#FFFFFF` | ページ背景 | body bg |
| `--rh-surface` | `#FFFFFF` | カード面 | — |
| `--rh-surface-alt` | `#F5F5F5` | セクション帯・淡い面 | 明灰 |
| `--rh-border` | `#E1E1E1` | 罫線・カード境界 | #E7E7E7 系 |
| `--rh-badge-bg` | `#FFF1E8` | 「伸びしろ」等バッジ背景（淡いオレンジ） | 補助アクセント |

ダーク/ライト両対応は必須ではない（店頭スマホ・白基調前提）。ライト固定でよいが、
将来のために色は変数化して1箇所で切替可能にする。

## 2. タイポグラフィ

- フォント: `"Hiragino Sans","Hiragino Kaku Gothic ProN","Yu Gothic","Meiryo",system-ui,sans-serif`
- 本文 16px / 行間 1.6 / weight 400。補助 14px。
- 見出し: h1 20–22px・h2 17–18px、weight **700**、色 `--rh-heading`。
- 価格: 太字 700・`--rh-price`・本文より一段大きく（例 18–20px）。「¥」記号付き、3桁区切り。

## 3. 形状・余白・影

- 角丸: 基本 `--rh-radius: 4px`、カードは `--rh-radius-lg: 8px`。
- 影: 控えめ `--rh-shadow: 0 1px 3px rgba(20,41,58,.08)`（カード/ヘッダーに軽く）。
- 余白: 8pxグリッド（8/12/16/24）。モバイル1カラム、コンテンツ最大幅 640px 中央寄せ。
- タップ領域: ボタン/リンクは最小高さ 44px（スマホ操作）。

## 4. コンポーネント様式

- **ヘッダー**: 白背景＋下罫線、左に「Room Harmony」ワードマーク（テキスト、ブランド色のドット/ロゴ枠はプレースホルダ）。上端に `--rh-brand` の細い帯（4px）でブランド感。
- **主要ボタン（CTA）**: `--rh-primary` 背景・白文字・700・角丸4px・最小高さ44px。hover で `--rh-primary-hover`。例:「この商品の場所を見る」「このコーデで揃える」。
- **副ボタン**: 白背景・`--rh-primary` 文字＋1px `--rh-primary` 罫線（アウトライン）。例:「商品へ進む」「場所を見る」。
- **商品/関連カード**: 白面・1px `--rh-border`・角丸8px・軽い影。商品名（`--rh-heading`）＋**価格（`--rh-price` 太字）**＋副ボタン。画像は 1:1 プレースホルダ、`ImageWithFallback` 維持。
- **価格表示**: 常に赤・太字・¥・3桁区切り。
- **バッジ（「伸びしろ」等）**: `--rh-badge-bg`/`--rh-badge-text`・小さめ・角丸4px。
- **コーデ詳細**: 完成イメージを大きく（全幅・角丸8px）、構成商品リストは行区切り、合計金額は価格色で強調、CTAは主要ボタン。
- **マップ/ルート（SVG）**: 経路線は `--rh-brand`（太め）、目的地ピンは `--rh-price`、サブ通路は破線＋淡色、フロア切替はセグメント型（アクティブ=主要色）。凡例は小さめ。
- **管理ダッシュボード（/admin）**: KPI棒グラフは treatment=`--rh-brand`／control=灰(`#B6B6B6`)。diff 正=ブランド色/負=価格赤。表は罫線 `--rh-border`。※内部向けのため装飾は控えめ。
- **来店ロック/エラー**: 赤系ではなく `--rh-surface-alt` の案内カード＋主要ボタンで誘導（エラーは `--rh-price` の細字メッセージ）。
- **チャットボット導線**: 副ボタン（アウトライン）＋アイコン風。

## 5. 実装方針

- トークンは `frontend/src/theme.css`（新規）に `:root` の CSS 変数として集約し、`main.tsx` で読み込む。
- 既存の `App.css` はトークン参照へ置換（色の直書きを変数に寄せる）。コンポーネント側は既存の
  `className`/`data-testid` を維持（テストを壊さない）。**構造・テキスト・testid は変更しない**、見た目のみ。
- モバイルファースト・レスポンシブ・PWA を維持。
- アクセシビリティ: コントラスト AA を目安（主要ボタンの白文字は大/太字で 3:1 以上、本文/リンクは 4.5:1 目安）。
